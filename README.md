# GunmanContracts_Provolver
Protube devices support for Gunman Contracts

## Installation
1. Get the [MelonLoader installer](https://melonwiki.xyz/#/?id=automated-installation) and install the latest version on your game executable.
2. Download the [latest release](https://github.com/Astienth/GunmanContracts_Provolver/releases/download/1.0/Gunman_Contracts_Provolver.zip) of the mod and unzip the contents into game folder.
3. Start the game. Wait a few seconds and your protube devices will vibrate upon connection.

## Featured effects
- Fire
- Reload: eject/insert magazine, cocking, auto reload
- Grabbing weapon

## Dual Wield

If using two or more Protube devices, it will automatically set hand based on device channel: channel pistol1 will be right hand and channel pistol2 will be left hand.
It creates files in the game directory in the folder UserData: right.pro and left.pro.
If you want to modify what devices to use with what hand:
- if using two provolvers: let the mod do its thing then modify if you want to swap hand, then swap the physical device or if for any reason you need to change the hand, rename right.pro to left.pro and left.pro to right.pro
- if using a provolver and a protube: make sure before first launch of the mod that both are on the same pistol1 channel. Otherwise, delete the left.pro and right.pro files, force both devices on the pistol1 channel using the companion app and start the mod again.
